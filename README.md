# Formal Invite

A small static invitation website inspired by the simple yes/no flow of the reference site.

## Files
- index.html — invitation page
- yes.html — celebration page after she says yes
- style.css — design
- script.js — buttons, SMS link, confetti

## Before publishing
1. Open `script.js`.
2. Replace `04XXXXXXXX` with your mobile number.
3. Change the wording in `index.html` / `yes.html` if you want.
4. Upload all files to a GitHub repository.
5. In GitHub: Settings → Pages → Deploy from branch → main / root.
6. Send the generated GitHub Pages link.

## Optional personalisation
- Replace the emoji illustration with a photo of the two of you or a formal-themed image.
- Add her first name to the heading.
- Add the venue if you want the invitation to include it.

The “I can’t” button does not run away or trap the person. It gives a simple respectful response.
