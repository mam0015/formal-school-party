FORMAL INVITE - GITHUB PAGES FILES

Upload ALL files in this folder to the ROOT of your GitHub repository:

- index.html
- style.css
- script.js
- config.js

Then enable GitHub Pages:
Settings -> Pages -> Deploy from branch -> main -> /(root)

IMPORTANT:
Before publishing, open config.js and replace:
PASTE_YOUR_FORMSPREE_ENDPOINT_HERE
with your real Formspree endpoint.

Example:
https://formspree.io/f/abcdwxyz
